# Границы системы

В разработку бота входит интерфейс работы преподавателя (репетитора), интерфейс учащегося, панель администрирования системы. Напоминания и оповещения о событиях для всех связанных участников.
В разработку не входят: веб-интерфейс для дополнительных функций, кроме админки, в т. ч. для создания слотов.

## Диаграмма границ системы:
```mermaid
%%{init: {"flowchart": {"curve": "linear"}}}%%
flowchart LR
    %% ===== АКТОРЫ (объявлены первыми, без subgraph) =====
    Student["🧑‍🎓<br/><b>Учащийся</b>"]
    Teacher["🧑‍🏫<br/><b>Преподаватель</b>"]
    Admin["🛡️<br/><b>Администратор</b>"]

    %% ===== СИСТЕМА =====
    subgraph Bot["💬<b>  Чат-бот «Регистрелло»</b>"]
        direction TB

        subgraph ForStudent["Учащийся"]
            direction TB
            SelectTeacher(["👨‍🏫 Выбрать<br/>преподавателя"])
            SelectSlot(["📅 Выбрать<br/>слот"])
            BrowseRecord(["📖 Просмотреть<br/>записи"])
        end

        subgraph ForTeacher["Преподаватель"]
            direction TB
            BrowseSlot(["🗓️ Просмотреть<br/>слоты"])
            BrowseSched(["📅 Просмотреть<br/>расписание"])
            NewSlot(["➕ Создать<br/>слот"])
            EditSlot(["✏️ Редактировать<br/>слот"])
        end

        subgraph ForAdmin["Администратор"]
            direction TB
            ViewReport(["📊 Смотреть<br/>отчёты"])
            FixIssue(["🛠️ Устранять<br/>проблемы"])
        end

        subgraph ForSystem["Сервис уведомлений"]
            direction TB
            SendMsg(["📨 Рассылать<br/>сообщения"])
        end
    end

    TgApi["🤖<br/><b>Telegram Bot API</b><br/><i>внешняя система</i>"]

    %% ===== АССОЦИАЦИИ =====
    Student ==> SelectTeacher
    Student ==> SelectSlot
    Student ==> BrowseRecord

    Teacher ==> BrowseSlot
    Teacher ==> NewSlot
    Teacher ==> EditSlot
    Teacher ==> BrowseSched

    Admin ==> ViewReport
    Admin ==> FixIssue

    SendMsg ==>|"отправка сообщения"| TgApi 

    TgApi -.->|"ответ: ok / 429 retry_after"| SendMsg
    

    %% ===== INCLUDE / EXTEND =====
    SelectSlot -.->|include| SelectTeacher
    BrowseSched -.->|extend| BrowseSlot

    %% ===== СТИЛИ =====
    classDef actor fill:#0ea5e9,stroke:#0369a1,stroke-width:2px,color:#ffffff,font-weight:600;
    classDef studentUC fill:#e0f2fe,stroke:#0284c7,stroke-width:1.5px,color:#075985;
    classDef teacherUC fill:#dcfce7,stroke:#16a34a,stroke-width:1.5px,color:#14532d;
    classDef adminUC fill:#fce7f3,stroke:#db2777,stroke-width:1.5px,color:#831843;
    classDef systemUC fill:#ede9fe,stroke:#7c3aed,stroke-width:1.5px,color:#3b0764;

    class Student,Teacher,Admin,TgApi actor;
    class SelectTeacher,SelectSlot,BrowseRecord studentUC;
    class BrowseSlot,BrowseSched,NewSlot,EditSlot teacherUC;
    class ViewReport,FixIssue adminUC;
    class SendMsg systemUC;

    style Bot fill:#f8fafc,stroke:#cbd5e1,stroke-width:2px,color:#0f172a;
    style ForStudent fill:#f0f9ff,stroke:#bae6fd,stroke-dasharray:4 3,color:#0c4a6e;
    style ForTeacher fill:#f0fdf4,stroke:#bbf7d0,stroke-dasharray:4 3,color:#14532d;
    style ForAdmin   fill:#fdf2f8,stroke:#fbcfe8,stroke-dasharray:4 3,color:#831843;
    style ForSystem  fill:#f5f3ff,stroke:#ddd6fe,stroke-dasharray:4 3,color:#3b0764;
```
