# Описание системы

Чат-бот "Регистрелло" предназначен для планирования занятий преподавателями и обучающимися через приложение "Telegram". Приложение упрощает процесс организации занятий и делает людей ближе, помогает передаче знаний.
В нашей системе каждый преподаватель может создать удобное для себя расписание занятий основанное на слотах. Повторы занятий могут генерироваться автоматически. Зарегистрировать на определённое время учащихся по договорённости, просмотреть и отредактировать своё расписание. Обучающийся может выбрать и забронировать в расписании у определённого преподавателя желаемое время для занятия, просмотреть своё расписание и скорректировать, при необходимости, удалив или изменив время.
