# Критерии приёмки

## 1. Функциональность
- Реализованы все функциональные требования из раздела [[03. Назначение#Функции системы]]. 
- Пользователь может зарегистрироваться, изменить роль / удалить данные.
- Создавать, удалять, редактировать слоты. Выбирать преподавателей, записываться на определённое время на занятия. Получать сообщения о связанных с ним операциях.
- При создании/изменении/отмене записи обе стороны получают сообщение, факт отправки добавляется в логи.
## 2. Тестирование
- Код покрыт unit-тестами (не менее 80%).
- Все тесты проходят успешно.
## 3. Качество кода
- Код соответствует стандартам PEP 8.
- Используются линтеры (ruff, black) и они не выдают ошибок.
- Проект имеет осмысленную структуру и комментарии.
## 4. Развертывание
- Приложение запускается командой docker compose up без дополнительных действий.
- Все переменные окружения корректно загружаются из .env.
## 5. Документация
- README содержит описание проекта, инструкцию по запуску, описание основных функций.
- При необходимости в коде оставлены комментарии к сложным участкам.
