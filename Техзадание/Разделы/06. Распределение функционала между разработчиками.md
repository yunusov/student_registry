# Распределение функционала между разработчиками

Требуется чтобы для разработки системы каждый из разработчиков изучил работу во всех предлагаемых направлениях - front-end - разработка форм, ввод и вывод данных, back-end - обработка бизнес-логики, импорт-экспорт данных, разработка базы данных. Стоит поделить проект на функциональные части и вести разработки относительно параллельно.
