# Системные требования

## Интерфейс взаимодействия системы
Для взаимодействия пользователя с системой используются возможности предоставляемые API Telegram-бота - кнопки и текстовые команды. 

## Технологии разработки
Проект разрабатывается на Python с использованием библиотеки aiogram.
В качестве линтеров используется ruff/black.
Docker compose для сборки образа и развёртывания приложения.
Настройки приложения хранятся в .env.
**PostgreSQL** - СУБД.

## Нефункциональные требования
### Производительность
Время ответа на основные действия (создание, редактирование) не более 1 секунды при штатной нагрузке.
### Масштабируемость
Архитектура разделена на слои (модели, репозитории, сервисы, маршруты), что позволяет легко добавлять новый функционал.
### Тестируемость
Код покрыт unit-тестами (сервисы, репозитории) с использованием pytest.
Наличие интеграционных тестов для основных сценариев.
### Развертывание
Приложение упаковывается в Docker-контейнер.
Используется docker compose для локальной разработки (PostgreSQL + приложение).
