# «Регистрелло» — техническое задание

Чат-бот для планирования занятий между преподавателями и учащимися (Telegram).

## Структура хранилища
- `Техзадание/` — [[00. Оглавление]] и 8 разделов в `Разделы/`
- `Схемы/` — [[00. Схемы]] (`01. Сценарий.canvas`)
- `Мета/` — [[Аудит]], [[Бэклог]], [[Соглашения]], [[Глоссарий]], [[CHANGELOG]]
- `Шаблоны/` — шаблон нового раздела ТЗ

## Как работать
1. Новый раздел: Шаблоны → «Раздел ТЗ»
2. Перед сдачей: закрыть задачи в [[Бэклог]], прогнать [[Аудит]]
3. Правила оформления и терминология: [[Соглашения]], [[Глоссарий]]
