# Аудит

__Пустые заметки (требуют наполнения):__
```dataview
LIST
FROM "" 
WHERE file.size = 0
  AND file.folder != "Шаблоны"
```

__Нет frontmatter (нет тегов):__

```dataview
TABLE file.folder AS Папка, file.size AS Размер
FROM ""
WHERE length(file.etags) = 0 AND file.ext = "md"
```


__Незаполненные заглушки:__
```dataview
TABLE file.folder AS Папка
FROM -"Шаблоны"
WHERE file.ext = "md" AND (contains(file.content, "{to-do}") OR contains(file.content, "[[]]"))
SORT file.folder ASC
```


__Статьи без входящих/исходящих ссылок__
```dataview
TABLE file.folder AS Папка
FROM -"Шаблоны"
WHERE length(file.outlinks) = 0 AND length(file.inlinks) = 0
```


__Устаревшие разделы (> 30 дней):__

```dataview
TABLE status AS Статус, updated AS Обновлено, file.mtime AS Изменён
FROM #тз
WHERE date(today) - date(updated) > dur(30 days)
SORT updated ASC
```

__Ссылочный баланс (ищем односторонние связи):__

```dataview
TABLE length(file.outlinks) AS Исходящие, length(file.inlinks) AS Входящие, file.etags AS Теги
FROM -"Шаблоны"
SORT length(file.inlinks) ASC
```

__Открытые задачи из ТЗ:__

```dataview
TASK
FROM "Техзадание"
WHERE !completed
GROUP BY file.link
SORT rows.file.name ASC
```
